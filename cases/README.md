# Test cases

Five finance back-office processes for evaluating the allocation tool.

## Rules
- Synthetic. The company ("Nordbakk AS", fictional) and all wording are written for this repo.
  Each case lists the public sources its step sequence is modelled on.
- No numbers. Volumes, minutes and costs are left for the person running the test to supply.
- Steps are numbered so Haakon's baseline and the tool's output can be compared step by step.
  Step extraction from un-numbered text gets evaluated separately later.

## Source verification
The build sandbox could not open the source pages (network policy). The sources were
found through web search, and the step patterns come from search-result summaries,
not from reading the documents. Before the case study cites any of them, open the link
and confirm it says what the case assumes.

## Baseline workflow
1. Haakon fills in `baseline.md` in each case folder, before running the tool on that case.
2. Optional: the sparring partner reviews the same file and adds their own column.
3. Only then run the tool and record agreement/disagreement.
